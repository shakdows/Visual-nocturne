# Visual Nocturne

Cámara nocturna para el celular: toma fotos y graba video con poca luz, y guarda todo en el teléfono.

- **Luz automática**: mide la escena y amplifica la imagen (hasta ×10) promediando fotogramas para reducir el ruido.
- **Visión verde**, linterna y cambio de cámara.
- Cada captura se descarga al celular y queda en la galería de la app (Guardar / Compartir / Borrar).
- Se puede instalar en la pantalla de inicio y abre sin conexión.

Es una web estática (sin compilación). La cámara solo funciona servida por `https://` o en `localhost`:

```
npx serve .
```
